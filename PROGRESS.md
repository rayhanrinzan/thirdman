## Passing-lane consistency fix

The overlay, sequence validator, curated route finder, and opposition outlet arrows now share one lane check. Every pass is checked using the board at that action, including prior movements and endpoint pressure. Blocked live results are rejected. Curated routes use open supporting teammates within four passes, or omit unreachable connections with an explanation. Response arrows use a straight open lane; blocked direct outlets are labeled unavailable.

## Reactive opposition — implementation checkpoint

Main sequences now use a deterministic 50 ms defensive model: the nearest two outfield defenders approach the ball after a reaction delay, the rest shift compactly, and goalkeepers hold. A shared swept interception forecast checks moving defenders across the whole pass. Pass timing is engine-controlled by distance. Stateful routing can revisit a teammate after circulation draws pressure away, and pressured carriers can release before waiting for off-ball runs. Low-block receiving movement was adjusted to retain a viable combination.

Playback is compiled once per preview. Pause, scrub, apply and undo retain the same defensive positions. Pressers are highlighted, and the passing overlay shows the current in-flight pass rather than projecting new options from a player who has already released the ball. Validation so far: lint, TypeScript, 42 engine/server tests and production build pass; full desktop/mobile acceptance is next.
